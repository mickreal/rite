# Design artboards

Source HTML of the seven artboards from the Rite design artifact (https://claude.ai/artifact/L1Mby8bJobVpQMmbLLVC26), kept here so
code can be diffed against the design without the artifact: Main (landing), Flow (mobile stepper), Result, Reading, ShareCard,
OgImage, SignAries. They use a tiny template runtime (`{{…}}`, `<sc-if>`, `<sc-for>`) and won't render standalone; read them for
structure, classes, keyframes and copy. `canvas.json` is the artboard layout.
