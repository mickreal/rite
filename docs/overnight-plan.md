# Overnight work plan

What the unattended sessions do while Mick is offline, how they work, and what they must not touch. Each night's run is a
scheduled task that starts a fresh cloud session, clones `mickreal/rite`, works on a branch `overnight/<YYYY-MM-DD>`,
commits with clear messages, pushes, and opens a pull request. **It never deploys, never touches Stripe, Resend, D1 or
KV, and never edits `wrangler.toml` or anything under `.dev.vars`.** Mick reviews the PR over coffee and merges or not.

## Night 1 (first run)

1. **Per-sign pages, finished.** `src/content/signs.ts` has one `about` and one `questions` paragraph per sign. Add, for
   each of the twelve: an opener line for the hero (one sentence, specific to the sign, no keyword stuffing), a
   "who this is for" sentence that uses the computed birth ranges, three FAQ pairs that only that sign would have, and a
   meta description under 155 characters. Wire them into `src/views/sign.ts` (FAQ as a simple list, same `.faq` style as
   the landing). Render all twelve locally with `wrangler dev --local` and Playwright, check every date reads sensibly
   including second-return cohorts, and save screenshots to `docs/qa/<date>/signs/`.
2. **Launch content kit v2** at `docs/launch-kit-v2.md`, replacing the Polsia-era kit's content sections. Everything
   dated must come from the ephemeris table (`src/content/saturn-daily.json` via `saturnLongitude`, or
   `scripts/gen-sign-periods.ts` output), not memory. Deliver: 10 short-video scripts (TikTok/Reels, 20–40 s, hook in
   the first line, one on-screen date), 10 X/Threads posts, 5 Instagram carousel outlines (slide-by-slide text), 3
   Reddit explainers written to be useful without a link (r/astrology, r/AskAstrologers, r/SaturnReturn if it exists;
   check the rules of each first and note them), 2 newsletter pitch emails. Re-verify the celebrity table from the old
   kit against the code and drop anyone whose birth time is unknown and whose degree is near a sign boundary. Hooks
   organised by cohort: first return Apr 1996–Jun 1998 and Oct 1998–Feb 1999 (Aries), the Taurus cohort that opens in
   2028, and the second-return 1967–69 cohort.
3. **Email copy drafts** at `docs/emails.md`: the three existing templates reviewed for voice (see `VOICE` in
   `src/content/prompts.ts`), plus drafts for a day-3 "did you add the dates" nudge and a day-10 Saturn Season nudge.
   Copy only; no scheduling code.
4. **QA sweep.** `npm test`, `npx tsc -p .`, then Playwright screenshots of `/`, `/start` (all steps), `/p/:id` (seed a
   preview locally), `/r/:tok` with the seeded report from `test/` fixtures if present (else skip), `/gift`,
   `/privacy`, `/terms`, `/refunds`, four sign pages, at 390 px and 1280 px. Write findings to `docs/qa/<date>/report.md`:
   what's broken, what's off against the design artboards in `docs/design/` if present, nothing speculative. Fix only
   clear defects (typos, overflow, broken links); describe anything bigger rather than redesigning it.
5. **Morning summary** as the PR description: what changed, what to look at first, open questions.

## Night 2 (if night 1 merged cleanly)

- PNG share card: render `card.ts` SVG to PNG via Cloudflare Browser Rendering or resvg-wasm; add `/card/:id.png`.
  Keep the SVG route. Needs a decision on Browser Rendering (paid add-on) vs resvg (bundle size), so propose both in the
  PR with measurements; implement resvg unless told otherwise.
- Second-return landing variant: `/second` with copy for 56–60-year-olds; same form, different hero and FAQ.
- `og.png` per sign page: twelve pre-rendered PNGs in `public/og/`, generated by a script from `card.ts`'s dial.

## Rules for every run

- Branch off `main`, never commit to it. One PR per night. Small commits.
- Do not change prices, prompts' date rules, the window definition, or anything in `src/astro/`.
- Do not create accounts, send email, or call Stripe, Anthropic, Resend or PostHog write APIs. Local dev only; the
  `AI` binding and secrets aren't available and that's fine.
- If a step needs a decision (a dependency, a design change), write the options in the PR and move on.
- Stop at four hours of work. A half-finished PR with a clear summary beats an unfinished one with none.
